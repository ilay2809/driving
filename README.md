# סימולטור נהיגה — צפון תל אביב

סימולטור נהיגה תלת-ממדי בדפדפן ללימוד נהיגה ותיאוריה לרישיון **B (רכב אוטומט)** בישראל.
העולם בנוי מרשת הכבישים האמיתית של צפון תל אביב — עבר הירקון: רמת אביב, נווה אביבים, אפקה,
תל ברוך, שיכון ל', כוכב הצפון, הדר יוסף, צהלה, רמת החייל ואוניברסיטת ת"א — מתוך OpenStreetMap
והנתונים הפתוחים של עיריית תל אביב-יפו (≈ 6,000 קטעי כביש, 4,500 צמתים, 360 רמזורים, 14,800 מבנים).

## מצבים

| מצב | מה קורה |
|---|---|
| **שיעורי נהיגה** | 15 שיעורים מדורגים (L00–L14) עם מורה נהיגה וירטואלי שיושב לידך: תדריך עם תמרורים ודיאגרמות, הוראות קוליות וכתוביות, משוב מיידי על כל טעות, התערבות בבלם כפול, חידון תיאוריה בתוך הנסיעה ותחקיר בסוף. |
| **נהיגה חופשית** | סיבוב חופשי בצפון ת"א מ-13 נקודות התחלה, שליטה בתנועה, שעה ומזג אוויר; עם המורה ("שיעור חופשי") או בלי — תמיד בכפוף לחוקי התנועה ("מוניטור חוקים"). |
| **טסט** | מבחן נהיגה מעשי עם בוחן וירטואלי: 4 מסלולים אמיתיים (או מסלול אקראי), הוראות כמו בטסט, תמרונים (עצירה בצד, נסיעה לאחור, פניית פרסה, חניה מקבילה, בלימת חירום), בלימה כפולה בסכנה, ותעודת תוצאות. |
| **תיאוריה** | מאגר השאלות הרשמי של משרד התחבורה (1,273 שאלות לרישיון B), מבחן מדומה (30 שאלות / 40 דק'), ספריית 119 תמרורים, ספר חוקים ב-31 פרקים. |
| **מגרש אימונים** | עיירה סינתטית קטנה עם רמזור, תמרור עצור, תן זכות קדימה, כיכר, רחוב חד-סטרי, אזור 30 ואבני שפה צבעוניות — לתרגול ממוקד. |

## שליטה

| פעולה | מקש |
|---|---|
| גז / בלם | ↑ / ↓ (או W / S) |
| היגוי | ← / → (או A / D) |
| חגורה · התנעה (עם בלם לחוץ) | B · I |
| הילוכים P / R / N / D | P / R / N / D (יציאה מ-P עם בלם לחוץ) |
| בלם חניה | רווח |
| איתות שמאלה / ימינה / חירום | Q / E / X |
| מבט למראה שמאל / פנימית / ימין | 1 / 2 / 3 |
| בדיקת נקודה מתה שמאל / ימין | Z / C |
| אורות · מגבים · צופר | L · V · H |
| הסבר מהמורה · מצלמת מעקב · עזרה · השהיה | ? · F3 · F1 · Esc |

נתמכים גם גיימפד (מיפוי סטנדרטי) והגה (Logitech/Thrustmaster) דרך Gamepad API.

## הרצה

```bash
pnpm install
pnpm dev            # http://localhost:5173
```

קובץ העולם (`public/world/north-tlv.json.gz`) ותוכן הלימוד כבר כלולים בריפו. לבנייה מחדש מהמקורות:

```bash
NODE_USE_ENV_PROXY=1 pnpm world:all      # OSM + GIS עירוני → public/world/north-tlv.json.gz (+ data/world-stats.json)
NODE_USE_ENV_PROXY=1 pnpm content:theory # מאגר השאלות הרשמי → data/content/theory.json
pnpm content:signs                        # קטלוג התמרורים → public/signs/*.svg + data/content/signs.json
```

בדיקות: `pnpm check` (typecheck + lint + 420 בדיקות יחידה), `pnpm build && pnpm e2e` (Playwright, כולל נסיעה אמיתית במגרש האימונים ובצפון ת"א).
דפי פיתוח: `/dev/world-viewer.html`, `/dev/world-map.html`, `/dev/vehicle.html`, `/dev/traffic.html`, `/dev/coach.html`, `/dev/ui.html`, `/dev/content.html`.
