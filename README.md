# סימולטור נהיגה — צפון תל אביב 🚗

סימולטור נהיגה תלת-ממדי בדפדפן ללימוד נהיגה ותיאוריה לרישיון **B (רכב אוטומט)** בישראל.
העולם בנוי לפי רשת הכבישים האמיתית של צפון תל אביב (עבר הירקון: רמת אביב, נווה אביבים,
אפקה, תל ברוך, שיכון ל', כוכב הצפון, הדר יוסף, צהלה, רמת החייל, אוניברסיטת ת"א) מתוך
OpenStreetMap והנתונים הפתוחים של עיריית תל אביב-יפו.

## מצבים

- **שיעורי נהיגה** — מורה נהיגה וירטואלי יושב לידך, מסביר כל חוק, נותן הוראות, ומגיב מיד לכל טעות.
- **נהיגה חופשית** — סיבוב חופשי בעיר, עם המורה ("שיעור חופשי") או בלי ("לבד"), תמיד בכפוף לחוקי התנועה.
- **טסט** — מבחן נהיגה מעשי עם בוחן וירטואלי: הוראות כמו בטסט אמיתי, תמרונים, בלימה כפולה, ודוח תוצאות.
- **תיאוריה** — מאגר השאלות הרשמי של משרד התחבורה, קטלוג תמרורים וספר חוקים.
- **מגרש אימונים** — עיירה סינתטית קטנה עם כל סוגי הצמתים לתרגול ממוקד.

## הרצה

```bash
pnpm install
pnpm world:all      # (פעם אחת) הורדת OSM + GIS ובניית קובץ העולם
pnpm content:theory # (פעם אחת) ייבוא מאגר שאלות התיאוריה
pnpm dev            # http://localhost:5173
```

בדיקות: `pnpm check` (typecheck + lint + unit tests), `pnpm build && pnpm e2e` (Playwright).
